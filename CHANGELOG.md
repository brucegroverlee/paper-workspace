# Changelog

## 1.0.0

First public preview on the Visual Studio Marketplace and Open VSX.

- Infinite canvas of movable, editable code papers (file nodes with snippets, folder nodes, targets).
- Syntax colors from your installed grammars and color theme, Git gutter, minimap.
- Shapes, notes, text and images for diagrams.
- Workspaces panel with Off / Manual / Take over modes.
- Snapshots to PNG, duplicate, copy & paste between workspaces, export / import as `.paperbundle`.
- Copy reference and an AI skill for agents that read and build workspaces.
